## 实现节奏（老大确认）

- **新弹药一种一版验收**，不要一口气全做。
- 当前运行时：战斗/奖励池为**平庸 + 所选罪孽 + 已验收新弹**（墓碑已进池；幽灵仅战斗内/开发工具，不进奖励）。其余新弹按验收节奏逐个启用。
- **运行时 id**：设计表编号与 `data/ammo.json` id 不必相同（罪孽设计 2–4 → 运行时 16–18；墓碑/幽灵设计 9–10 → 运行时 19–20）。旧彩色弹占 2–15 且 `enabled_in_combat=false`。
- 色欲 / 嫉妒 / 暴食 / 懒惰（编号 5–8）表内为空壳，标注「未实装」。

## 罪孽说明（无独立编号行）

初始弹药袋有 **5 颗罪孽子弹**，**不能被删除**。  
若一次装填达到 **3 颗**罪孽，会触发负面效果（具体负面由所选罪孽种类决定，见对应罪孽弹行与枪口状态表）。

开局由玩家选择一种罪孽（愤怒 / 傲慢 / 贪婪）装入袋中；色欲等空壳罪孽暂不可选。

### 2. 愤怒子弹

- **稀有度**：（空）
- **基础伤害**：3
- **特殊机制**：每 1 颗愤怒子弹被发射时，给枪口挂上 1 层【愤怒】。一次装填 3 颗：对玩家自己造成 6 点伤害
- **概括**：枪口 爆发加伤
- **备注**：（空）
- **视觉效果设计**：填装越多，玩家颜色越红，填第三发时玩家最红，然后扣血并恢复原本颜色

### 3. 傲慢子弹

- **稀有度**：（空）
- **基础伤害**：2
- **特殊机制**：每 1 颗傲慢子弹被发射时，给枪口挂上 1 层【傲慢】。一次装填 3 颗：把敌人拉到玩家面前
- **概括**：枪口 增长式加伤
- **备注**：（空）
- **视觉效果设计**：傲慢层数越多，玩家颜色越紫

### 4. 贪婪子弹

- **稀有度**：（空）
- **基础伤害**：2

### 9. 墓碑子弹 — **已实装**（运行时 id=19）

- **稀有度**：（空）
- **基础伤害**：2
- **特殊机制**：每 1 颗墓碑子弹被发射时，生成一个幽灵子弹在子弹袋里，并且当墓碑子弹被发射后，立即用子弹袋里的幽灵子弹填充满当前弹夹的空位
- **概括**：召唤 爆发
- **备注**：（空）

- **视觉效果设计**：在子弹袋里悬浮漂浮状态，如果子弹袋里有墓碑子弹，则会在墓碑子弹周围漂浮

### 13. 石头子弹

- **稀有度**：（空）
- **基础伤害**：3
- **特殊机制**：每 1 颗石头子弹被发射并击中敌人后，会变成等于造成实际伤害数字的数量的小石头子弹，例如 1 颗石头子弹对敌人造成了 5 伤害，会变成 5 个小石头子弹加入子弹袋
- **概括**：子弹增生
- **备注**：（空）
- **视觉效果设计**：不规则几何体（形似圆形但不是很圆），像石头

### 14. 小石头子弹

- **稀有度**：（空）
- **基础伤害**：1
- **特殊机制**：通过石头子弹生成在子弹袋里，战斗结束后消失。当弹夹里有 ≥2 个小石头子弹连在一起时，他们会融合成 1 个石头子弹，例如有 3 颗小石头子弹在弹夹里相连，那么第一颗击发判定时检测到后面也是小石头子弹，则不击发，直接转到下一个弹仓，然后把上一个小石头子弹的伤害叠加在这个小石头子弹上，也就是 2，以此类推，3 颗小石头子弹变成了 1 颗 3 伤害的石头子弹，然后检测下一个弹仓不是小石头子弹，则发射现在的石头子弹
- **概括**：多子弹合体
- **备注**：（空）
- **视觉效果设计**：不规则几何体（形似圆形但不是很圆），像石头，小号版

### 15. 散射子弹

- **稀有度**：（空）
- **基础伤害**：5
- **特殊机制**：射击后，实际伤害均分给所有敌人，四舍五入。如果敌人小于 3 人，则每个人只受到实际伤害 30%，四舍五入。
- **概括**：AOE
- **备注**：（空）
- **视觉效果设计**：分成若干成枪线，射向每个敌人

### 16. 保险子弹

- **稀有度**：（空）
- **基础伤害**：1
- **特殊机制**：保险子弹在子弹袋里时：当轮盘即将填装第 3 颗罪孽子弹时，将即将填装的罪孽子弹替换成保险子弹，以避免触发 3 颗罪孽的惩罚
- **概括**：减少惩罚概率
- **备注**：（空）
- **视觉效果设计**：填装第三颗罪孽子弹时，先把第三颗罪孽子弹装进去，然后从子弹袋里飞上去把它换上去，把罪孽子弹换下来
