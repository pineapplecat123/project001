## 裁定（2026-10-23 用户确认）

1. **黑色弹药**：仅当黑色数量**严格最多**时，本次装填全部伤害 ×3；与其它颜色**并列最多**则**不触发**。
2. **金色弹药**：射击后触发的是玩家**当前回合内的特殊动作**（额外装填并自动射击），**不跳过**怪物回合；弹夹内有几发金就进行几轮自动装填射击。
3. **黑白弹药**：若本局尚无「上次装填」记录，则**不生效**（保持自身，不变形）。
4. **粉色弹药**：同一次 UNLOAD 中多发粉色只计**一次**永久提升；所有粉色**共享**本局永久 +1（每成功 unload 含粉一次 +1）。
5. **黄色 / 紫色**：基础伤害为「变化」；该颜色**每一发**都按数量 / 相连公式取**同一个**伤害值（例如 3 发黄 → 每发都是 3）。
6. （跨表）行动力 = 每回合向玩家移动的格数。
7. （跨表）石头标签：无视每次**小于 4** 的伤害；一切具体数值以表为准。

## 灰盒启用

本模块战斗仅开放 **id=1 白色子弹**。其余弹药已入库为数据，战斗中默认 `enabled_in_combat=false`，后续按实现难度逐个启用。
