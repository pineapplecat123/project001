## 详情

### 1. 流血

- **持续时间**：每回合 -1 层
- **来源**：怪物标签特性
- **获得方式**：生物被攻击时
- **对象**：有【生物】标签的怪物
- **效果**：每回合结束时失去等同于层数的生命值，然后层数 -1
- **类型**：debuff
- **相关**：[`enemy-tags.md`](enemy-tags.md)「生物」

### 2. 燃烧

- **持续时间**：每回合 -1 层
- **来源**：火焰子弹（经枪口【火焰】附加；层数＝子弹伤害）
- **获得方式**：怪物被攻击时
- **对象**：怪物
- **效果**：每回合结束时将燃烧层数的一半分给相邻怪物（向上取整，数字高的流向数字低的），然后失去等同于层数的生命值，然后层数 -1
- **类型**：debuff
- **相关**：[`muzzle-status.md`](muzzle-status.md)「火焰」「炸药」；[`ammo.md`](ammo.md)「火焰子弹」「炸药子弹」
