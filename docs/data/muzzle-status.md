## 详情

### 1. 愤怒

- **持续时间**：从挂上枪口到回合结束
- **效果**：每层带来 100% 的加伤
- **层数限制**：无
- **来源弹药**：愤怒子弹（每发射 1 颗挂 1 层）

### 2. 傲慢

- **持续时间**：整局战斗
- **效果**：每层带来 25% 的加伤，并且受到怪物的攻击伤害也会加 25%
- **层数限制**：无
- **来源弹药**：傲慢子弹（每发射 1 颗挂 1 层）

### 3. 贪婪

- **持续时间**：从挂上枪口到回合结束
- **效果**：敌人受伤掉落金币，每层获得 30% 概率，掉落金币量＝子弹造成的伤害
- **层数限制**：无
- **来源弹药**：贪婪子弹（每发射 1 颗挂 1 层）

### 4. 穿甲

- **持续时间**：从挂上枪口到回合结束
- **效果**：子弹可以击穿怪物，对第一个怪物造成一次全值伤害，之后伤害 -1，对下一个怪物造成伤害，以此类推直到这次伤害数值减到 0
- **层数限制**：最多 1 层
- **来源弹药**：穿甲子弹

### 5. 火焰

- **持续时间**：从挂上枪口到回合结束
- **效果**：射击敌人附加等于子弹伤害的层数【燃烧】状态
- **层数限制**：最多 1 层
- **来源弹药**：火焰子弹
- **相关 buff**：见 [`buffs.md`](buffs.md)「燃烧」

### 6. 炸药

- **持续时间**：从挂上枪口到回合结束
- **效果**：射击处于【燃烧】状态的敌人，对被击中敌人及其左右相邻的 N 个敌人（N=实际伤害-2，至少=1）造成 3 倍伤害
- **层数限制**：最多 1 层
- **来源弹药**：炸药子弹

### 7. 回声

- **持续时间**：从挂上枪口到回合结束
- **效果**：每发子弹发射两次
- **层数限制**：最多 1 层
- **来源弹药**：回声子弹

### 8. 吸血

- **持续时间**：从挂上枪口到回合结束
- **效果**：每层吸血给子弹带来 20% 的吸血概率（最多 100%），攻击敌人后将造成伤害的 50% 转化为自己的生命值恢复
- **层数限制**：无
- **来源弹药**：吸血子弹
